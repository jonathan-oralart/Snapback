# Handoff: making the next demo

Start with [README.md](README.md) for commands. This file records what worked and what cost time in the October 2026 recording.

- **Reuse the existing take.** `scripts/record-demo.sh player` arranges the apps and replays two annotations through the real Debug annotation session. It does not start/stop CleanShot or submit to Claude. Build with `scripts/dev.sh`; keep its signing and bundle ID intact.
- **Keep the demo separate.** Claude's selected folder must be `../snapback-demo`, with the supplied `CLAUDE.md`. Preserve any wanted result before restoring its baseline. Send exactly one image, with no prompt text.
- **Compose before recording.** Use regular Chrome with tabs/address bar, Claude left and Chrome right, margins around both, unrelated apps hidden. The take requires a 600 × 700 point Chrome window. Changing zoom or browser chrome can move the targets even when the window size matches.
- **CleanShot needs its API enabled.** Settings → Advanced → API → Allow applications to control CleanShot. Disabled API calls silently did nothing. Enable cursor, click highlights and command-key display; disable audio/camera. The README's capture coordinates are for the original display, not every Mac. Capture enough space above the windows for Snapback's toolbar.
- **Plan the manual steps.** In the successful take the user pressed ⇧⌘2, clicked Send to Claude and submitted the image (the button is now Copy & Open Claude, followed by ⌘V). Simulated global shortcuts were unreliable. If the physical shortcut also fails, re-record it in Snapback Settings; that fixed this session. Karabiner remaps Right Command on this machine, so use Left Shift + Left Command + 2. We did not establish Karabiner as the cause.
- **Arm first, then record.** Start recording once the script reports the take is armed; activation expires after about two minutes. Restart the script if it expires. Progress is in `build/demo/player.times`; avoid opening Snapback during the take, which can bring up Settings.
- **Let the actions breathe.** Keep both notes, padded selection boxes, the second note bubble above its box, and Extra large exported text. Show the actual Copy & Open Claude click and the ⌘V paste; pause about three seconds after the image appears before submitting. CleanShot supplies the click/shortcut indicators. No explanatory title or artificial button highlight is needed.
- **Inspect the actual final page.** Claude can open a preview despite `CLAUDE.md`; close it and trim that interruption. A quiet file or Claude's completion message does not prove the browser shows all edits. Reload if necessary and verify both the wrapped title and square artwork before holding the final shot for several seconds.
- **Judge exported footage.** Recorder-overlay screenshots sometimes looked blank even though the saved video was fine. Save raw footage under ignored `build/demo/`. Use the tracked exporter below, not old experiments in that directory; cut timings must be chosen afresh for each recording.

Export instructions are in [README.md](README.md#exporting). Review the MP4, contact sheet and final GIF before replacing `docs/demo.gif`. The approved demo is about 36 seconds, 1280 pixels wide, 15 fps and 5 MB. Keep activation, annotation, image-only submission and the verified result visible at a glance.
